**El Dorado Launcher** for **Uncharted: The Nathan Drake Collection** on PC. **Beta 1**: the first public build.

Extract the zip anywhere, start **Uncharted Launcher.exe** and choose your game folder (the one with
eboot.bin and sce_sys). No game files are included: you play your own copy (update 1.02 is recommended: most
fixes and the cheats need it).

## Highlights

- 🗺️ **One launcher for the three games, in 22 languages** (Arabic right to left), each game in its own color.
- 🌍 **Your copy's own languages:** read from your game files, a fan translation included, in its own place.
- ⚡ **Prepare shaders before you play:** the first start opens straight away, and the cache is never lost on exit.
- 🎮 **Straight to the main menu**, with loading screens in the launcher's look.
- ⌨️ **Key prompts that read as keys**, in English or any keyboard layout of your Windows.
- 🛡️ **Alt+F4 asks first**, so a slip of the hand keeps your progress.
- 💾 **Saves with pictures, backups and players.**
- 🎯 **Cheats for all three games**, and **Damage to Nate**: play Crushing while Nate takes damage as on Easy.
- 🧰 **Problem report** and **Check El Dorado.bat** when something goes wrong.

## The launcher

- **A new home screen** for mouse, keyboard and controller: each game with where you left off, your play time,
  last play, average FPS and trophy progress, and a big PLAY. Each game has its own color (Uncharted 1 green,
  2 blue, 3 orange).
- **22 languages**, Arabic first and right to left, and every game language your copy holds: the launcher
  reads them from your game files, so a fan translation shows in the place of the language it replaced.
- **Players:** named profiles, each with its own saves.
- **Settings** per game (display, performance) or for all games (controls, language, game files, launcher,
  cheats); one set of controls for the three games, with each game's own keys where you want them.
- **Prepare shaders** (Settings > GAME FILES): the three games' shaders before the first start, so each game
  opens straight away.
- **Saves, Trophies and Gallery** pages; backups of every changed save before each start.
- **Problem report** (Settings > LAUNCHER): the logs and settings in one zip on your Desktop.
- **Check El Dorado.bat** next to the launcher: checks the install and the last runs (crashes, how each game
  was closed, FPS, the shader cache) and shows it as one page.

## In the games

- **A fast engine** with DLSS, FSR 3.1, FSR 4, XeSS and frame generation.
- **Loading and shader preparation screens** in the launcher's look; the title page is passed by itself and
  each game stops at its main menu.
- **El Dorado's in-game menu** (Insert, or L3 + R3 on a controller), in your language, with an FPS / GPU / CPU
  / RAM / VRAM counter and checkpoints and save slots.
- **Key prompts** drawn as keyboard keys in the game's colors; the letters in English (US) or any keyboard
  layout installed in Windows (Insert > Key letters). Keys work by their place on the keyboard.
- **The close button and Alt+F4 ask first**, so a slip of the hand does not lose the play since the last save.
- **Saves** with a picture of the moment they were made; Delete / Triangle (Y) twice deletes one.
- **Mouse on mounted guns** (Uncharted 1's jeep gun and the turrets of all three games).
- **Cheats** (Settings > CHEATS): infinite ammo and grenades, no reload, one hit kills, all treasures (once),
  every reward unlocked, every chapter, and **Damage to Nate**: on any difficulty, Nate takes damage as on
  Explorer, Easy, Normal or Hard.

## Known issues

- Uncharted 1: one crash was seen once when entering the jungle after the temple (the game's own memory heap);
  it did not happen again. If you hit it, please send the Problem report.
- The in-game menu shows Korean and Traditional Chinese in English (its font has none of their characters).
